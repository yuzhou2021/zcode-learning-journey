# ZCode 学习案例

一份「用 AI 编程助手从零开始学做小项目」的完整学习档案。核心成果是 [todo.html](todo.html)：一个单文件、零依赖、开箱即用的待办清单应用，历经九步迭代打磨到 v2.6.4。

## 我是怎么学的

2026 年 9 月，我用 AI 结对编程工具 ZCode 开始学编程。方法和常见的「让 AI 全代办」相反：

- 每一步练习由我本人动手完成：先按练习卡组织需求话术，由我确认后再实现，实现后亲自验收；
- ZCode 只做三件事：示范方法、解释代码、执行我明确委托的事务性工作；
- 第 5 步曾因 AI 直接代做而整体回退重练——这份档案里也保留了这个教训。

完整的学习地图、问题档案、练习卡和心得都在 [学习总览.html](学习总览.html) 中（GitHub 不直接渲染 HTML，请下载后用浏览器打开）。

## 九步学习路线

以 todo.html 为主线，每一步只加一个主题：

1. 增删改查
2. 标签
3. 日期
4. 导入导出（JSON，带内容校验码，支持跨设备迁移）
5. 搜索
6. 四区布局与界面优化
7. 拖拽排序
8. 外观五主题（浅色 / 石墨黑 / 午夜蓝 / 暖夜棕 / 随系统）
9. 子任务 + 界面统一打磨（图标选型、像素级对齐）

## 文件说明

| 文件 | 作用 |

| `学习总览.html` | 学习进度总档案（学习地图 / 问题档案 / 练习卡 / 心得） |
| `外观方案预览.html` | 第 8 步配色选型档案 |
| `图标方案预览.html` | 第 9 步图标选型档案 |
| `AGENTS.md` | 给 ZCode 的会话须知（本项目的学习规则） |

## 如何使用

克隆或下载本仓库后，直接用浏览器打开 `todo.html` 即可，无需安装任何依赖。数据保存在浏览器 localStorage 中，不随文件同步；应用内提供 JSON 导入 / 导出（带内容校验码），可用于跨设备迁移数据。

计算器同理，浏览器直接打开 `calculator.html`。Python 练习需要 Python 3 环境：先自己找 `ledger_stats.py` 里的 bug，再对照 `ledger_stats_fixed.py`。
