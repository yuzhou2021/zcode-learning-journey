    操作说明

    • 新增：右栏「✨ 新增」打开表单；标签可选已有或新建（每条最多 3 个，新标签限 6 字）；回车或「添加」保存，新事项加入顶部
    • 编辑：双击标题 / 简述就地修改（回车保存、Esc 取消）；点 ✎ 改标签 / 日期 / 优先级；点五角星切换优先
    • 完成：点事项左侧方框勾选 / 取消
    • 删除：点 ✕ 并确认，删除后不可恢复
    • 筛选与搜索：顶部状态按钮（全部 / 未完成 / 已完成 / 优先 / 截止日）与左栏标签可同时生效；搜索在其结果上二次过滤，Esc 或 × 清空
    • 拖拽排序：悬停事项，简述右下出现「⠿ 拖拽」手柄（与 ✕ 对齐），按住上下移动，指示线指到哪、松手放到哪；筛选中可拖（改真实顺序），搜索或子任务展开期间暂不支持；收起子任务后手柄回来
    • 子任务：悬停事项，简述左下出现「🔽 子任务」（与五角星对齐；有子任务的事项常亮提示，展开后变 🔼），点击在事项下方展开子任务列表；列表底部始终有一条空行等待输入——回车保存后自动续行、失焦自动保存、Esc 清空；双击子任务文字可编辑；勾选表示该子任务完成（划线），× 删除；再点按钮或点事项空白处收起。子任务不改变父任务的完成状态
    • 标签工具：左栏「📊 标签统计」查看各标签数量；「🏷️ 标签管理」改名 / 换色 / 删除，删除在用标签需双重确认（事项保留）
    • 导入导出：右栏「📤 导出」可勾选部分待办下载 JSON；「📥 导入」支持覆盖 / 追加并校验认证码——数据存浏览器本地，换设备靠它迁移
    • 缩放：右栏「🔍 缩放」调整界面大小，面板与按钮持平对齐
    • 外观：右栏「🎨 外观」选择浅色系 / 石墨黑 / 午夜蓝 / 暖夜棕 / 随系统（随系统在系统深色时用石墨黑）；选择自动记住，刷新保持
